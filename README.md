🚑 JEEVANROUTE

Smart Rural Emergency Ambulance & Hospital Routing System

About the Project

JEEVANROUTE is a C++-based emergency ambulance and hospital routing system designed to improve emergency response in rural and remote areas. It helps prioritize patients, assign available ambulances, select suitable hospitals based on medical facilities, and calculate efficient routes.

The project demonstrates the practical application of Data Structures and Object-Oriented Programming (OOP) to solve a real-world healthcare problem.

Objectives

- Prioritize emergency patients according to their medical condition.
- Manage ambulance availability and assignments.
- Select suitable hospitals based on required medical facilities.
- Calculate efficient routes using graph algorithms.
- Notify hospitals before the patient's arrival.
- Apply Data Structures and OOP concepts using C++.

 Key Features

-  Patient Management: Store patient details and emergency information.
-  Emergency Prioritization: Handle critical cases using a priority queue.
-  Ambulance Management: Track ambulance availability and status.
-  Smart Hospital Selection: Consider ICU beds, CT scans, specialists, and other required facilities.
-  Route Optimization: Represent road networks using graphs and calculate suitable routes.
-  Hospital Pre-alert: Support advance notification of incoming patients.
-  Modular Design: Organize the system using C++ classes and objects.

 Technologies Used

- Programming Language: C++
- Core Concepts: Data Structures and Object-Oriented Programming
- Data Structures: Arrays, linked lists, queues, priority queues, and graphs
- Algorithms: Graph traversal and shortest-path algorithms
- Development Tools: Any C++-compatible IDE or compiler

 Data Structures and OOP Concepts

Concept| Application
Priority Queue| Prioritizing emergency cases
Graph| Representing roads and locations
Queue| Managing emergency requests
Arrays / Lists| Storing patient, ambulance, and hospital records
Classes and Objects| Modeling system entities
Encapsulation| Protecting and organizing data
Inheritance| Reusing common class properties
Polymorphism| Supporting flexible system behavior

 System Workflow

1. Register the patient and record the emergency details.
2. Assess the severity and assign a priority level.
3. Identify an available ambulance.
4. Evaluate hospitals based on distance and required facilities.
5. Calculate a suitable route to the patient and selected hospital.
6. Dispatch the ambulance and send a hospital pre-alert.
7. Update the ambulance and emergency request status.

 Future Enhancements

- Real-time GPS tracking of ambulances.
- Live traffic-based route optimization.
- Online hospital database integration.
- Real-time ICU bed and specialist availability.
- Mobile application for emergency requests.
- Automated notifications to hospitals and healthcare workers.

Limitations

JEEVANROUTE is an educational prototype. Its recommendations depend on the accuracy of the available data and implemented algorithms. It does not replace professional medical judgment or official emergency dispatch services.

Academic Purpose

This project is developed as a Project-Based Learning (PBL) project to demonstrate the practical application of Data Structures and Object-Oriented Programming in C++.
